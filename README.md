A tiny Python program that writes one funny, true one-line review of a boring everyday object to `/output/entry.txt`. The review takes the dustpan: it sweeps up the whole mess, yet always leaves one thin grey line of dirt behind — because its lip never sits flush — and signs the floor with it.

Run it with `python3 main.py` (writes `/output/entry.txt`; set `OUTPUT_DIR` to override the output directory).
