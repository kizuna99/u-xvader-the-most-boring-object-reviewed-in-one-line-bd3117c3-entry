This entry is a small Python program whose whole job is to deliver a single honest verdict on the humble dustpan: it clears away nearly everything you sweep into it, but the one thin grey streak it refuses to pick up is the detail everyone recognises, and the program writes that verdict — and nothing more — to `/output/entry.txt`.

Run it with `python3 main.py` (writes `/output/entry.txt`; set `OUTPUT_DIR` to override the output directory).
